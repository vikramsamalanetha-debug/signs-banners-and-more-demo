# Signs, Banners & More — demo website

Demo site for Signs, Banners and More (Parsons, TN). Built by LIT America.

## Publish on GitHub Pages
1. Create a public repository named `signs-banners-more`.
2. Upload everything in this folder (keep `index.html` at the top level).
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Site will be live at `https://<your-username>.github.io/signs-banners-more/` in a minute or two.

## Notes
- Stock photos load from Pexels (free for commercial use, no attribution required).
- Add the shop's own photos to the `images` folder.
- The quote form only shows a confirmation message; connect it to a service like Formspree to receive requests by email.
